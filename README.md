My Library App

A simple library application built with HTML, CSS, and JavaScript.
Users can add books, mark them as read or unread, remove books, and keep their library saved using localStorage.

Features

Add new books through a form

Display books as cards

Toggle read / unread status

Remove books from the library

Show and hide the add book form

Persist data using localStorage

Built With

HTML

CSS

JavaScript

How It Works

Books are stored in an array and created using a Book constructor.
The interface is generated dynamically from this data.
Any change updates the UI and localStorage.

Getting Started

Open index.html in your browser and click New Book to add books.
No installation or dependencies required.
